# 🌌 Portafolio Web 3D / Cinemático // Next.js App

Este directorio contiene el código fuente de la aplicación Next.js del Portafolio Web 3D de **Federico Marcenac**.

## 📖 Documentación de Transferencia para Claude AI / Desarrolladores
Toda la documentación técnica maestra, inventario de assets y especificación de animaciones se encuentra en el directorio raíz:
- **`../CLAUDE_START_HERE.txt`**: Guía rápida ejecutiva para Claude AI.
- **`../HANDOFF_CLAUDE.md`**: Documento maestro de transferencia técnica.
- **`../ASSETS_INVENTORY.md`**: Inventario completo de imágenes, frames y renders.
- **`../ANIMATIONS_SPEC.md`**: Especificación matemática y temporal de animaciones.
- **`../README.md`**: Documentación general del proyecto.

## 🚀 Comandos Rápidos
```bash
npm install     # Instalar dependencias
npm run dev     # Servidor de desarrollo en http://localhost:3000
npm run build   # Compilar export estático en ./out (para GitHub Pages)
npm run lint    # Ejecutar ESLint
```
