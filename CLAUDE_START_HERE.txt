1. QUE ESTAMOS CONSTRUYENDO
--------------------------------------------------------------------------------
Un portafolio web personal y comercial de estetica cinematografica / cyberpunk,
desarrollado en Next.js (App Router, Turbopack, Tailwind CSS v4, TypeScript).
El sitio utiliza un motor de scrubbing continuo en Canvas HTML5 donde el scroll
del usuario reproduce fluidamente 557 fotogramas renderizados a 60 FPS con
interpolacion LERP, acompanado por interfaces de cristal templado (glassmorphism)
de alto contraste para presentar los proyectos, trayectoria y contacto del autor.

3. QUE ARCHIVOS DE CODIGO DEBES INSPECCIONAR
--------------------------------------------------------------------------------
Todos los archivos fuente estan dentro de esta misma carpeta "my-app/":
- app/page.tsx:
  El orquestador de la SPA. Define el contenedor de 950vh, el sticky viewport de
  100dvh y monta las capas sincronizadas con globalFrame.
- app/components/ContinuousScrollCanvas.tsx:
  El motor canvas continuo que carga y dibuja los 557 frames con DPR cap 2 y modo
  cover total sin franjas negras.
- app/components/ProjectsCards.tsx:
  Las 4 tarjetas de proyectos con cables ciberneticos SVG interactivos, animacion
  de entrada lateral y salida hacia la izquierda, y carrusel snap para celulares.

  Perfil personal con foto 3:4 real, formacion UTN + Coderhouse y stack badges.
- app/components/ContactSection.tsx:
  Tarjeta de contacto con boton funcional para copiar email y links a redes.
- app/globals.css:
  Text-shadows de neón con pixel outline perimetral de 8 direcciones para legibilidad.
- next.config.ts:
  Configuracion de export estatico (output: 'export') y basePath para GitHub Pages.

6. QUE DECISIONES NO DEBES CAMBIAR
--------------------------------------------------------------------------------
- NO cambies la salida estatica (output: 'export'). El hosting es GitHub Pages.
- NO uses rutas absolutas duras como "/Frames/..." en los componentes; usa siempre
  el helper getBasePath() o NEXT_PUBLIC_BASE_PATH para soportar /Portafolio3D.
- NO elimines las clases de pixel-text ni el fondo negro puro: garantizan que los
  textos se lean con total nitidez sobre cualquier fotograma del video.
- NO reemplaces el canvas por un elemento <video>: el elemento video no soporta
  scrubbing bidireccional suave cuadro a cuadro sin tirones.
- NO inventes datos personales ni cambies el nombre de Federico Marcenac.
- NO marques Torre Umbral como obra real construida: debe quedar explicitamente
  documentado como proyecto conceptual / maqueta arquitectonica 3D.
